> ⚠️ **Project Status:** This repository contains **Prototype 01** of an ongoing computer engineering project. The core logic architecture is currently being prototyped and tested in Python before integration with 3D simulation tools.

Life Support and Base Management System for an underwater habitat. This project will utilize NVIDIA Isaac Sim, Blender Python, and ROS 2 to create a digital twin that manages the components to sustain life, such as oxygen levels, adequate temperature, etc. The base also manages power allocation and hull integrity.
