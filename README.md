# Autonomous-Underwater-Habitat-Life-Support-System (Prototype 01)

![Status: In Active Development](https://img.shields.io/badge/Status-In%20Active%20Development-orange)
![Version: 0.1-prototype](https://img.shields.io/badge/Version-0.1--prototype-blue)

> ⚠️ **Project Status:** This repository contains **Prototype 01** of an ongoing computer engineering project. The core logic architecture is currently being prototyped and tested in Python before integration with 3D simulation tools.

Life Support and Base Management System for an underwater habitat. Inspired by the underwater game Subnautica. This project will use NVIDIA Isaac Sim, Blender Python, and ROS 2 to create a digital twin that manages components to sustain human life underwater, such as oxygen levels, adequate temperature, etc. The base also manages power allocation and hull integrity.
